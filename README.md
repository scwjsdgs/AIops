# 智能运维（AIOps）平台

本项目是一个集成了 AI 智能体大脑、Java 底座和现代化前端页面的智能运维平台。

## 架构说明
- **AI 大脑 (`aiops-agent` / `ops_agent`)**：负责故障诊断、智能问答、日志分析。
- **Java 底座 (`ops_agent` / 其他)**：提供核心业务逻辑、告警接收和自动化执行。
- **前端页面 (`ops-agent-front`)**：提供可视化的运维大盘和交互界面。

## 技术栈
- 前端：Vue/React（请根据实际修改）
- 后端：Java / Spring Boot
- AI：Python / LangChain / LLM
